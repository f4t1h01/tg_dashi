# tg_dashi

Telegram-бот (aiogram 3): принимает выгрузку СКУД «Passages through perimeter» (.xlsx)
и возвращает Excel-отчёт из трёх листов:

| Лист | Что внутри |
|---|---|
| **Сводка** | KPI, графики (по дням, распределение прихода, по отделам, топ-10). Фильтры: отдел, сотрудник, период, показатель графика, рейтинг. Настройки: учёт общежития / техпомещений, начало и конец дня, допуск опоздания |
| **За месяц** | Сотрудник × дата: приход / уход, подсветка статуса, итоги по сотруднику и по дню |
| **За день** | Плоский список «сотрудник × день» с автофильтром: приход, уход, точки, время на территории, опоздание, ранний уход |

Все листы считаются формулами, поэтому переключатели на «Сводке» пересчитывают всю книгу.
Значения для фильтров по умолчанию сохраняются в файле заранее, так что отчёт показывает цифры
и там, где формулы не пересчитываются (превью на телефоне).

## Правила расчёта

- Строки без даты и ФИО — продолжение дня сотрудника из строки выше, `(no)` — события нет.
- **Приход** — самый ранний проход за день в любую сторону, **уход** — последний выход.
- По умолчанию учитываются только КПП и турникеты; `Dorm*` (общежитие) и `* room` (техпомещения)
  включаются на листе «Сводка».
- Опоздание — приход позже начала дня + допуск; ранний уход — уход раньше конца дня (только рабочие дни).
- Отсутствие — рабочий день без проходов. Работа в выходной считается отдельно.

## Ветки и окружения

- `test` — разработка; на сервере крутится тестовый бот (`~/telegram_bots/tg_dashi_test`, `.env.test`).
- `deploy` — прод; обновляется мержем из `test` после проверки (`~/telegram_bots/tg_dashi`, `.env`).

```bash
# тест
ENV_FILE=.env.test COMPOSE_PROJECT_NAME=tg_dashi_test DEV=1 docker compose up -d --build
docker compose -p tg_dashi_test run --rm bot python -m pytest -q
# прод
ENV_FILE=.env COMPOSE_PROJECT_NAME=tg_dashi docker compose up -d --build
```

Переменные окружения — в `.env.example`.

## Локально без бота

```bash
pip install -r requirements-dev.txt
python -m app.cli выгрузка.xlsx отчёт.xlsx
python -m pytest -q
```
